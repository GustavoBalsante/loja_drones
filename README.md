# DroneShop - E-Commerce de Drones

Aplicação web completa de e-commerce para venda e gerenciamento de drones, desenvolvida com Python, Django e Tailwind CSS.

## Funcionalidades

- **Catálogo de Produtos:** Exibição dinâmica de drones com fotos, preços e ficha técnica.
- **Página de Detalhes:** Visualização individual do tempo de bateria, alcance em km e descrição.
- **Carrinho de Compras:** Sistema flexível gerenciado via sessões do Django (adicionar, alterar quantidade e remover).
- **Checkout e Pedidos:** Formulário de envio com gravação de pedidos no banco de dados.
- **Painel Administrativo:** Gestão nativa do Django para cadastrar produtos, alterar estoque e visualizar vendas.

## Tecnologias Utilizadas

- **Backend:** Python, Django
- **Frontend:** HTML5, Tailwind CSS
- **Banco de Dados:** SQLite
- **Pagamentos:** Stripe (API Integration)
